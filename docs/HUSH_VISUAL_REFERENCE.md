## Hush translation

- Keep the main action in a compact floating Flow Bar that is always reachable.
- Use a calm workspace with a high-contrast graphite rail, warm paper canvas, and one coral recording signal.
- Treat recording, processing, and ready states as distinct visual states with short, scannable copy.
- Keep the desktop shell lightweight: one Tauri process, local state, and lazy model work behind the existing Meetily recording pipeline.

The references guide interaction hierarchy and visual rhythm. Hush does not ship Wispr Flow artwork, source code, or branding.
